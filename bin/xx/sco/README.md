# scox: Oracc Score Generator

## harvest-links.plx

### index_text()

This read the XTF and generated a hash a key PROJECT:PQX~LABEL for
each MTS and val xml:id where the xml:id is either that of an
enclosing <lg> or the MTS <l> itself.

For the C version, ax generate a base label-xmlid table (.tlx) and
that is used to generate a hash emulating the harvest-links approach.
